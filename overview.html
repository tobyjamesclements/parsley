Parsley is a Java library for causal consistency over Kafka. It ensures that every consumer processes messages in the correct causal order, even when records originate from multiple topics and partitions, by encoding each message's causal dependencies onto it and buffering records until those dependencies have been observed.

The entire public surface lives in a single package, {@link io.parsley}, and consists of interfaces and value types; every implementation is package-private and obtained through a builder factory ({@link io.parsley.CausalProducers}, {@link io.parsley.CausalConsumers}, {@link io.parsley.CausalProcessors}).

Core concepts

Causal frontier
The highest offset observed on each topic-partition, keyed by topic UUID so that topic deletion and recreation produce a distinct identity even when the name is reused. Carried as {@link io.parsley.CausalFrontier}; combine two frontiers with {@link io.parsley.CausalFrontier#merge merge}.
Causal dependencies
The minimum frontier a downstream consumer must have observed before a record may be delivered — the upstream producer's snapshot of what it had seen when it sent the record. Carried as {@link io.parsley.CausalDependencies} in a {@code parsley-vector-clock} header. A record is causally ready when {@link io.parsley.CausalDependencies#isSatisfiedBy isSatisfiedBy} returns {@code true} against the consumer's current frontier.
Causal buffer
Records whose dependencies are not yet satisfied are held in a changelog-backed buffer and released as soon as the frontier catches up. A {@link io.parsley.CausalBufferLimit} bounds how long or how large the buffer may grow; when it fires, a configurable {@link io.parsley.CausalBufferPolicy} decides whether to forward the record anyway ({@code forwardUnsafe}), drop it ({@code drop}), or route it to a dead-letter sink ({@code deadLetter}).

Entry points

TypePurpose
{@link io.parsley.CausalProducer}Stamps the current causal dependencies onto every record it sends; built via {@link io.parsley.CausalProducers}.
{@link io.parsley.CausalConsumer}A {@code poll()}-based consumer that delivers records in causal order; built via {@link io.parsley.CausalConsumers}.
{@link io.parsley.CausalProcessorSupplier}Wraps a user Kafka Streams {@code Processor} so its state access and {@code forward}s run behind the causal guarantee; built via {@link io.parsley.CausalProcessors}.

Typical usage

{@code
// Consume with causal ordering
CausalConsumer consumer = CausalConsumers.builder(
    List.of("prices", "orders"),
    CausalBufferPolicy.forwardUnsafe(CausalBufferLimit.ofDuration(Duration.ofSeconds(30))),
    consumerConfig,
    streamsConfig).build();
ConsumerRecords records = consumer.poll(Duration.ofMillis(100));
records.forEach(record -> process(record));

// Produce, propagating the consumer's causal position
CausalProducer producer = CausalProducers.builder(producerConfig).build();
producer.send(new ProducerRecord<>("events", key, event), consumer.frontier().toDependencies());
}
