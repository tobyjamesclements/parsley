Parsley is a Java library for causal consistency in distributed messaging systems. It ensures that every consumer processes messages in the correct causal order, even when records originate from multiple upstream producers and channels. Parsley ships with a Kafka Streams implementation but aims to support other messaging technologies over time.

Core concepts

Vector clock
A snapshot of causal progress. The Kafka implementation maps each topic-partition to the highest offset observed; other implementations may use different representations. A consumer's frontier is its current vector clock.
Causal ordering
A message is causally ready when the consumer's frontier dominates the vector clock embedded in the message header — meaning the consumer has already processed every message that happened-before this one.
Causal buffer
Records whose clock dependencies are not yet satisfied are held in a per-consumer in-memory buffer and released as soon as the frontier catches up. If the frontier never advances far enough, a configurable {@link io.parsley.BufferingPolicy} decides whether to forward, drop, or dead-letter the record.
Fence token
An opaque, URL-safe string that encodes a vector clock. Producers embed a fence token in each outgoing message; receiving consumers decode it and wait until their frontier dominates it before proceeding. Fence tokens allow causal ordering to be enforced across service boundaries (e.g. as an HTTP header or message attribute).

Typical usage

{@code
// Consume with causal ordering
CausalConsumer consumer = CausalConsumer.create(
    List.of("orders"),
    BufferingPolicy.ignore(BufferLimit.ofDuration(Duration.ofSeconds(30))),
    consumerConfig,
    streamsConfig
);
while (running) {
    ConsumerRecords records = consumer.poll(Duration.ofMillis(100));
    records.forEach(record -> process(record));
    // Obtain the current frontier as a fence token for cross-service use
    String encoded = consumer.fenceToken().encode();
}

// Produce with causal annotation
CausalProducer producer = CausalProducer.create(producerConfig);
FenceToken token = FenceToken.decode(encodedTokenFromRequest);
producer.send(new ProducerRecord<>("events", key, event), token);
}
