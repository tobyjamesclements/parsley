Parsley is a Java library for causal consistency over Kafka. It ensures that every consumer processes messages in the correct causal order, even when records originate from multiple topics and partitions, by encoding a vector clock onto each message and buffering records until their causal dependencies have been observed.

Core concepts

Vector clock
A snapshot of causal progress: a map from each {@link org.apache.kafka.common.TopicPartition} to the highest offset observed. A consumer's frontier is its current vector clock.
Causal ordering
A message is causally ready when the consumer's frontier dominates the vector clock embedded in the message header — meaning the consumer has already processed every message that happened-before this one.
Causal buffer
Records whose clock dependencies are not yet satisfied are held in an in-memory buffer and released as soon as the frontier catches up. If the frontier never advances far enough, a configurable {@link io.parsley.BufferingPolicy} decides whether to forward, drop, or dead-letter the record.

Package overview

PackagePurpose
{@link io.parsley}Shared vocabulary: vector clock, buffering policy and limit, violation handler, metrics.
{@link io.parsley.producer}{@code CausalProducer} — stamps a vector clock onto every record.
{@link io.parsley.consumer}{@code CausalConsumer} — a poll-based consumer that delivers records in causal order.
{@link io.parsley.stream}{@code CausalProcessorSupplier} / {@code CausalStreams} — build causally consistent Kafka Streams topologies.

Typical usage

{@code
// Consume with causal ordering
CausalConsumer consumer = CausalConsumer.create(
    List.of("prices", "orders"),
    BufferingPolicy.ignore(BufferLimit.ofDuration(Duration.ofSeconds(30))),
    consumerConfig,
    streamsConfig
);
ConsumerRecords records = consumer.poll(Duration.ofMillis(100));
records.forEach(record -> process(record));

// Produce, propagating the consumer's causal position
CausalProducer producer = CausalProducer.create(producerConfig);
producer.send(new ProducerRecord<>("events", key, event), consumer.frontier());
}
